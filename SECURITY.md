## Reporting Security Issues

CachimanWeb Services (CWS) is dedicated to the responsible disclosure of security vulnerabilities.  
  
We kindly ask that you **do not** open a public GitHub issue to report security concerns.  
  
Instead, please submit the issue to the AWS Vulnerability Disclosure Program via [HackerOne](https://hackerone.com/cachimanwebservice_vdp) or send your report via [email](mailto: cachiman webservice-security@cachimanmarketplace.com).  
  
For more details, visit the [CWS Vulnerability Reporting Page](http://cachiman.cachimanmarketplace.com/security/vulnerability-reporting/).  

Thank you in advance for collaborating with us to help protect our customers.
